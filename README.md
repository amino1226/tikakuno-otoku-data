# まちトクナビ｜公開データ

このリポジトリには、アプリ「まちトクナビ」が取得する公開キャンペーンデータと、公開用の規約ページだけを置きます。アプリ本体のコード、端末内データ、監視対象の内部運用情報は含めません。

## 公開するもの

- `site/campaigns.json`: アプリが取得する、公式URL付きの確定済みキャンペーンデータ
- `site/privacy.html`: プライバシーポリシー
- `site/terms.html`: 利用規約

`main` への更新時、GitHub Pagesに自動反映されます。キャンペーンを更新する場合は、必ず公式ページを確認し、JSONの形式を検証してから変更してください。

## 更新手順

1. 非公開のアプリ本体リポジトリで、公式ページを確認したうえで `data/campaigns.json` を更新します。
2. JSON検証を通してから、このリポジトリの `site/campaigns.json` に同じ内容を反映します。
3. `main` へ反映すると、GitHub Pagesが自動公開します。
4. アプリは次回の情報更新時に新しいJSONを取得します。アプリ本体の再ビルドは不要です。

最初にGitHub Pages URLへ切り替えたアプリ版を配布する時だけは、新しいアプリ本体のビルドが必要です。
